# ConsoleGate User Guides

Step-by-step install instructions for parents, one per console.

| Console | Guide |
|---|---|
| **JTAG/RGH Xbox 360** | [`xbox-360.md`](xbox-360.md) |
| **Softmodded Wii** | [`wii.md`](wii.md) |

Before installing on a console, set up the **Hub** (the always-on brain on your
home computer) — see the [parent setup guide](../implement/13-parent-setup-guide.md).
The Hub web page runs at `http://<hub-host>:8088/`.

**Key difference between the two consoles:** the Xbox 360 can **close a running
game** when time is up; the Wii **cannot** (a hardware limitation) — it enforces at
the next launch and **alerts you** if play runs past downtime. Each guide explains
this in plain language.
